    Lazy Propagation

    My favorite algorithmic trick: knowing which work can wait.

    In a segment tree (or a Fenwick / binary indexed tree), a range update could touch every element in the range. Lazy propagation refuses to do that work up front: it drops a lazy tag on the highest nodes that cover the range and moves on.

    Only when a later query actually walks through a node does it push_down() the pending tag to its children. Updates and queries both stay O(log n). 

    // apply pending work only when needed
void push_down(int node) {
  if (lazy[node] == 0) return;
  for (int child : {2*node, 2*node+1}) {
    tree[child] += lazy[node] * len(child);
    lazy[child] += lazy[node];
  }
  lazy[node] = 0;  // done. back to sleep.
}
